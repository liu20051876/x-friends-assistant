# X 好友互动助手

一个面向 Chromium 浏览器的 X 互动辅助扩展，当前源码版本为 **0.6.9**。支持读取关注关系和帖子、调用 DeepSeek 或硅基流动生成回复草稿、管理队列，以及在浏览器页面中执行回复和点赞。也支持生成原创帖子草稿，并在用户确认后发布。

## 使用前请注意

- 本项目会自动审核部分草稿，并具备批量自动回复和点赞能力；时间线采集可面向互关名单以外的账号。启用前请检查配置、队列和适用的平台规则。
- 本项目使用页面交互及 X 内部接口，不是 X 官方 API 客户端；页面和接口变化可能导致功能失效或结果不确定。
- 已知限制包括：跳过操作与发送可能发生竞争；回复框或发帖框关闭不一定代表发送成功；目标帖匹配失败时存在回退到首篇帖子的行为；结果不确定时队列可能继续执行；原创草稿最多保留 50 条。
- 浏览器本地存储可能保存 API 密钥。不要将密钥、浏览器配置、名单、数据导出文件或日志提交到公开仓库；帖子内容会发送给所配置的 AI 服务商以生成草稿。
- 功能依赖实际浏览器及 X 页面。本仓库提供的自动化测试使用模拟环境，不能证明真实环境下所有操作可靠。

## 安装

1. 打开 Chromium 浏览器扩展管理页面（Chrome：`chrome://extensions`；Edge：`edge://extensions`），启用开发者模式。
2. 选择“加载已解压的扩展”，选择本仓库的 `extension` 文件夹。
3. 根据需要在扩展中配置服务商，按浏览器提示授予访问权限。

请先从少量只读采集开始，检查生成结果与目标，再自行决定是否启用发送。更多界面和功能细节见 [扩展说明](extension/README.md)；如其中关于风险或成功判定的表述与上面的已知限制不一致，以上面的说明为准。

## 测试

在 `extension` 目录中使用 Node.js 运行测试脚本，例如：

```sh
node tests/run-tests.js
node tests/integration-check.js
node tests/safety-check.js
```
